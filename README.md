# codex-igor.dev

Um pequeno laboratorio para experimentar ideias com IA, onde o Codex ajuda a transformar rascunhos em codigo, codigo em aprendizado e aprendizado em novas possibilidades.

## Portal de documentacao

Este projeto agora inclui um portal de documentacao em Next.js com menu lateral, indice do assunto aberto, secoes de codigo, links relacionados e temas claro/escuro.

```bash
npm install
npm run dev
npm run build
```
